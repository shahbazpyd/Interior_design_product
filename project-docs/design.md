# UI/UX Design System (V2 Super Premium)

## Vibe & Concept
Ultra-luxury, cinematic, and immersive. The UI must feel like browsing a high-end architectural digest. Elements should float, reveal smoothly, and utilize negative space masterfully.

## Color Palette (Refined)
*   **Primary Background:** `#F9F8F6` (Warm Alabaster - richer than pure off-white)
*   **Surface/Card Background:** `#FFFFFF` (Pure White) or Glassmorphic overlays (`bg-white/70 backdrop-blur-md`).
*   **Primary Text:** `#121212` (Onyx Black - high contrast, extremely crisp).
*   **Secondary Text:** `#737373` (Neutral Gray).
*   **Accent/Action:** `#B89C72` (Antique Gold / Bronze - sophisticated and muted).

## Typography (Advanced)
*   **Display/Headings:** `Playfair Display` or a high-contrast serif. Used massively for dramatic effect (e.g., oversized hero text).
*   **Body Text:** `Inter` (Clean, spaced well with `tracking-wide` and `leading-relaxed`).

## Advanced Component Guidelines
*   **Animations:** 
    *   **Scroll Reveals:** Elements should fade up (`translate-y-10` to `translate-y-0`) as they enter the viewport.
    *   **Parallax:** Background images move slower than foreground content.
    *   **Page Transitions:** Smooth crossfades when navigating between Home, Portfolio, and Project Detail pages.
*   **Images:** Use large, edge-to-edge photography. Implement lazy loading and subtle scale-in animations on load.
*   **Buttons:** Magnetic hover effects or sweeping color fills instead of basic opacity drops.
*   **Navigation:** A transparent header that turns into a sleek glassmorphic bar on scroll.
